# 定位结论

1. 菜单栏次级额度已经按真实比例计算，但 14pt 内容区中的 7% 只有约 0.98pt；旧 45° 镂空纹理在 Retina 像素栅格和圆角裁切后几乎不可辨，是视觉呈现问题，不是把 7% 算成 0%。
2. Codex 旧日期来自 `auth.json` JWT 的历史 `chatgpt_subscription_active_until`。usage API 成功后仍把该过去日期写入 snapshot，导致独立的当前周期查询被短路。
3. 修复短路后，真实 `accounts/check` 响应包含 `renews_at`/`expires_at` 字段。解析器现已优先支持 `renews_at`，兼容 ISO-8601、Unix 秒与毫秒；本机当前会话实测两字段都为 `null`，所以正确结果是隐藏日期，而不是按月猜测或继续显示 7 月。
